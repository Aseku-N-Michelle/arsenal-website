# Arsenal FC Website

A simple multi-page website about Arsenal Football Club, built with HTML, CSS and Bootstrap.

## Pages

- **Home** (`index.html`): introduction and links to explore the club
- **Players** (`players.html`): the squad
- **History** (`history.html`): the story of the club
- **Seasons** (`seasons.html`): season-by-season performances
- **Transfers** (`transfers.html`): transfer news and signings

## Tech used

- HTML5
- CSS (`style.css`)
- Bootstrap

## How to run

1. Clone or download this repository.
2. Open `index.html` in any web browser.

No installation or build step is needed.

## Project structure

```
Asernal-site/
├── index.html
├── players.html
├── history.html
├── seasons.html
├── transfers.html
└── style.css
```
